Аддон полностью меняет внешний вид мини-карты и добавляет большое количество настроек.

- Готовые красивые стили мини-карты с тонкой настройкой. 
- Изменение размера и положения мини-карты. 
- Скрытие лишних кнопок вокруг карты. 
- Отображение координат на мини-карте. 
- Настройка текста локации и часов. 
- Возможность двигать связанные с мини-картой элементы интерфейса.
